# Basic WESTPA tutorial (new Python API)

This tutorial, adapted from
[tutorial 7.1](https://github.com/westpa/westpa_tutorials/tree/main/tutorial7.1-basic-nacl),
is meant to introduce WESTPA users to the new Python API.

## Tutorial files

- `topology.pdb` &ndash; PDB file specifying the molecular topology
- `initial_state.xml` &ndash; OpenMM XML file specifying the initial coordinates
- `init_and_run.py` &ndash; Python script for initializing and running a
  weighted ensemble MD simulation using WESTPA, OpenMM, and MDTraj
